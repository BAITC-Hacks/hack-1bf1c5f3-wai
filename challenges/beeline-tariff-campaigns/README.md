# Финальный агент тарифных кампаний Beeline

Каталог сохраняет структуру кейса организатора. Все данные и результаты синтетические. Полное описание решения, архитектуры и установки находится в [корневом README](../../README.md).

## Файлы решения

| Файл | Назначение |
|---|---|
| `agent.py` | Точка входа `Agent.act(env)`, пилоты и возврат финального плана |
| `candidate_research.py` | Группы аудитории и слабые исторические гипотезы |
| `campaign_planner.py` | Обновление оценок, выбор пилотов, планирование и резервная логика |
| `submission.csv` | Воспроизводимый план кампаний, полученный при seed 42 |
| `requirements.txt` | Зависимости numpy и pandas |
| `data/change_tariff.csv` | История для начальных оценок; нужна для воспроизведения сохранённого CSV |

Два вспомогательных модуля нужно сохранить рядом с `agent.py`. Финальный агент не зависит от `experiments/`. Скрипты организатора, справочники и руководство участника находятся в исходных местах.

## Официальная проверка

После установки зависимостей по [инструкции](../../README.md) выполните из этого каталога в активированном виртуальном окружении:

```powershell
python local_eval.py
python local_eval.py --runs 10
python make_submission.py
python -m unittest discover -s tests -v
```

В Windows без активации используйте `.\.venv\Scripts\python.exe` вместо `python`, если окружение создано здесь. Для проверки воспроизводимости запустите `make_submission.py` повторно и сравните CSV. Оценщик и генератор используют пути относительно текущего каталога.

## Работа с другими данными

Аудитория, тарифы, каналы, остатки ресурсов и наблюдения пилотов поступают через публичный интерфейс `env`. Агент строит гипотезы по предоставленным таблицам и уточняет решения по результатам пилотов.

История читается из `data/change_tariff.csv` относительно `agent.py`. Если она недоступна, используются нейтральные гипотезы. Это может изменить результат и содержимое `submission.csv`.

Для локальной замены данных сохраняйте имена файлов и схемы колонок организатора. Новая папка `input/` не нужна. См. [перечень данных](data/README.md) и [руководство участника](PARTICIPANT_GUIDE.md).

Исследовательские скрипты, архивные агенты, искусственные эффекты и производные таблицы собраны в [experiments/](experiments/README.md). Они не используются финальной стратегией.
