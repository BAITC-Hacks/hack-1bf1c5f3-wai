# Research archive and tools

This folder contains development evidence and reproducible alternatives. The
active submission is the three Python modules in the parent directory; it does
not import code or read results from this folder. All data and effects here are
synthetic.

Run the commands below from the challenge directory with its virtual environment
activated. Some commands regenerate result files. Frozen snapshots preserve their
original source and import names; use the supplied loaders to compare them.

| Material | Location |
|---|---|
| Historical Git baseline comparison | `benchmark_agents.py` |
| Pilot and planner experiments | `pilot_*.py`, `planner_*.py` and associated JSON reports |
| Public-interface fault tests and effect shifts | `robustness_public_contract.py`, `robustness_shift.py` |
| Teammate comparison | `compare_main.py`, `main_comparison.md`, `main_snapshot/` |
| Historical-model integration study | `integrate_prior.py`, `borrow_prior.py`, `transition_prior.py`, `integration_*.json` |
| Frozen candidates from that study | `integration_baseline/`, `integration_rejected/`, `integration_rank_snapshot/` |
| Generated test effect tables | `robustness_shift_models.csv`, `integration_effect_worlds*.csv` |
| Derived participant history | `prepared_history/`, generated by `prepare_history.py` |

```powershell
# Compare the active agent with the earlier Git version.
python experiments/benchmark_agents.py --baseline-ref 0655b5c --start-seed 30 --runs 30 --output experiments/recheck.json

# Regenerate summaries without changing organizer input files.
python experiments/prepare_history.py

# Reproduce the two rejected integrations on their reserved scenarios.
python experiments/integrate_prior.py --stage validation --candidate rejected
python experiments/integrate_prior.py --round 2 --stage validation --candidate rank_rejected
```
